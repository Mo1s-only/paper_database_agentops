# Reference Paper

Store source papers, Chain-translated PDFs, deep-reading notes, and parsed text files here.

Recommended naming:

- Original paper PDF: `PaperName.pdf`
- Chain translation PDF: `PaperName(Chain).pdf`
- Deep-reading note: `PaperName_论文精读笔记.md`
- Parsed text: `PaperName_text.txt`

Keep paper-derived claims traceable to the PDF, note, or parsed text file.
