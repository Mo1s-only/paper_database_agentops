# 周报（2026-10-14 ~ 2026-10-20）

**一句话总结：**本周完成 Who&When、TRAIL、AgentTrace 三个公开数据集的统一协议兼容验证（882 条记录），并运行了 error-propagation-v1 与 AgentRx 的受限真实 API 样本；真实运行确认 AgentSight 能持久化 eBPF 进程、文件和网络侧观测，但 LLM／工具语义记录仍为 0，因此“多数据集均形成日志—系统—eBPF 完整数据链”的目标尚未通过。

**本阶段主工作：**把公开数据集适配和真实运行采集分成两道验证门。公开数据可完整进入归因前统一记录并保留原始证据定位；真实 API 样本则暴露 AgentSight 旧二进制与当前源码不一致、语义表为空的问题。本周的核心结论是：数据集格式兼容已通过，跨层采集链仍需修复并逐项闭合，不能把前者写成归因效果或完整链路成功。

## 1. 本阶段主要工作：从多数据集适配转向真实链路验证

### 1.1 三个公开数据集统一兼容

完成 Who&When、TRAIL、AgentTrace 到 `attribution-benchmark-record-v0.1` 的适配，并在全部本地数据上运行验证：

| 数据集 | 记录数 | 结构／关系结果 | 真值边界 |
|---|---:|---|---|
| Who&When | 184 | schema、证据定位与结构关系均 100% | 有 Agent／Step 责任标签；没有传播边与路径标签 |
| TRAIL | 148 | schema 与关系重建 100%，有 3 条适配警告 | 144 条错误 span 只作为 `partial` 步骤候选，不提升为根因或责任边 |
| AgentTrace | 550 | schema 与关系重建 100%，有 1 条路径边界警告 | 550 条含根因／路径标签；其中 549 条路径相邻节点与显式图边匹配，1 条为 partial |
| 合计 | **882** | 14,697/14,697 个结构关系机会重建；31,132/31,132 个对象有源定位和哈希 | 五类真值槽位总体 abstain 率 21.86%，表示数据未提供相应标签，不是适配失败 |

这项结果证明适配器能读取和忠实表达不同数据集的结构及标签粒度；没有运行归因算法，也没有证明任何模型准确率或 AgentSight 捕获率。完整报告见 [公开数据集兼容性实验](../lab/experiment/experiment_20261016_16/results_r3/compatibility-report.md)。

### 1.3 AgentSight 真实 eBPF canary 与源代码诊断

10 月 20 日再运行一次单会话 DeepSeek canary，CLI 成功，调用费用 `$0.0261024`，原生流记录了 Bash 和 Write 两次工具使用。eBPF／系统侧数据库包含 33 个进程节点、70 条审计事件（67 process、3 file），以及 `api.deepseek.com` 的网络目标；但 `llm_calls=0`、`tool_calls=0`、`token_usage=0`。所以当前已验证的是系统观测存在，未验证的是应用语义与系统事件已连成完整数据链。

这次运行的 CLI PID 和 eBPF PID 数字不同，但本方向已有 `process_identity.py`、`analyze_framework_process_clock.py` 和 10 月 10 日实验中的 PID／时钟流程。本次分析复用既有规则：缺少 `namespace_pid` 和共享 `tool_call_id` 时判 `abstain`。唯一命令与内核时钟只形成候选关联，不作为新贡献或同进程证明。

版本检查显示 WSL 当前调用的 AgentSight 安装目标文件修改时间为 2026-09-14；仓库中的 BPF helper 已包含 `namespace_pid` 输出，而本次原始 eBPF 行没有该字段，提示运行二进制可能落后于工作树源码。该差异仍需用当前源码二进制验证。完整单次报告与原始证据见 [10 月 20 日真实 eBPF 实验](../lab/experiment/experiment_20261020_21_agentsight_real_ebpf/实验报告.md)。

## 2. 当前数据链状态

```text
公开数据结构与标签适配 ── 已验证（882 条）
真实 Agent 原生运行日志 ── 已取得（若干会话）
AgentSight eBPF 进程／文件／网络记录 ── 已取得
LLM／工具语义落库 ── 本周 canary 为 0
跨层精确身份与完整关系 ── 未通过，按既有门控 abstain
```

由此，本周结果**不能**表述为“多个数据集已完成真实系统数据链验证”。公开数据集兼容性与真实在线观测是互补的两类证据，目前尚未在多个数据集任务上同时得到完整原生日志、系统事件、eBPF 事件和可审计的跨层链接。
