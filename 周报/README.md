# 周报

用于保存每一次提交给导师的周报。

文件命名要求：

```text
YYYY-MM-DD_周报.md
```

周报建议包含：

- 本周阅读论文；
- 本周实验或复现进展；
- 本周关键结论；
- 遇到的问题；
- 下周计划；
- 需要导师确认的问题。
