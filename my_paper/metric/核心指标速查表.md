# CERA 核心指标速查表

> 本表用于第一版“边级归因 + 局部拓扑修复”实验。公式、例子和注意事项见 [指标体系总览.md](指标体系总览.md)。

## 一、主结果指标

| 研究问题 | 主指标 | 必要配套指标 | 最低对照 |
|---|---|---|---|
| 能否找准失败传播边？ | Edge Precision / Recall / F1 | Edge Hit@1/3、MRR、多错误 Macro-F1 | 随机边、时间邻近边、节点级归因 |
| 预测边是否具有因果意义？ | 反事实下游消除效应 | 错误传播效应、可 Replay 率 | 随机边干预、假干预 |
| 边级修复能否挽救失败任务？ | 修复成功率 | 任务成功率、恢复时间 | 无干预、随机边修复、Prompt 修复 |
| 修复是否阻断错误且保留价值？ | 错误抑制率 + 洞察保留率 | Groundedness、任务质量 | 静态剪边、切断全部通信 |
| 自治干预是否安全？ | 误修复率 + 回归率 | 回滚率、置信度校准 | shadow/replay 后不写回 |
| 收益是否值得成本？ | 单成功任务成本 + 干预代价 | Token、端到端时延、Goodput | 等预算随机干预 |

## 二、数据准入指标

以下指标不合格时，不应声称获得可靠的边级因果结论：

| 准入项 | 指标 | 原因 |
|---|---|---|
| 调用配对 | 请求—响应配对 Precision / Recall / F1 | 配对错误会制造虚假的数据边和通信边。 |
| Trace 完整性 | 字段完整率、调用完整率 | 缺少输入、输出、配置或来源 ID 时无法可靠重放。 |
| Span 观测 | 分类型 Span 覆盖率 | 总覆盖率会掩盖 Tool、Evaluation 等关键类型缺失。 |
| 图重建 | 分类型 Edge Precision / Recall / F1 | “节点齐全”不等于“关系正确”。 |
| 证据追溯 | 原始证据保留率 | 必须能从结论回到原始事件。 |
| 因果验证 | 可 Replay 率 | 不可 replay 的样本最多支持相关性结论。 |
| 真值可靠性 | Cohen's κ / Krippendorff's α | 人工边标注本身需要可重复。 |

具体准入阈值不得直接照搬通用行业经验，应通过小规模标注、基线实验和任务风险共同确定。`AUTHOR_INPUT_NEEDED`

## 四、第一版实验建议暂缓的指标

温度漂移、E/token、P99.9、72 小时稳定性和 GPU 资源争抢边界并非不重要，但需要专门硬件、较大样本或长周期压测。若第一版论文以 CERA 为核心，可先保留接口，不将其设为必做主实验。
