# metric

本目录收录毕业论文中与多智能体 AgentOps、可观测性、故障归因和自治修复有关的评价指标。

## 文件说明

| 文件 | 用途 |
|---|---|
| [指标体系总览.md](指标体系总览.md) | 完整指标库。每个指标均包含定义、计算方式或判定口径、Agent 具体例子和论文用途。 |
| [官方标准与规范依据.md](官方标准与规范依据.md) | 区分现行国标/国际标准、官方框架、在研智能体标准和 OpenTelemetry/MLPerf 行业规范，并映射到 CERA。 |
| [论文依据与指标定义.md](论文依据与指标定义.md) | 依据近年顶会论文区分原定义、论文改造和 CERA 新定义，并给出公式与适用边界。 |
| [参考文献.md](参考文献.md) | 收录指标所依据论文、标准、官方框架和行业规范的元数据、官方链接及本地 PDF 映射。 |
| [核心指标速查表.md](核心指标速查表.md) | CERA 第一版实验建议优先报告的核心指标及对照关系。 |
| [实验结果记录模板.md](实验结果记录模板.md) | 实验运行、统计汇总和结论约束的可复用模板。 |

## 使用顺序

1. 先在《官方标准与规范依据》中判断来源是现行标准、官方框架、在研草案还是行业规范；
2. 再在《论文依据与指标定义》中确认指标是论文原定义、论文改造还是本课题新定义；
3. 到《指标体系总览》中查看计算口径、Agent 例子和适用范围；
4. 使用《核心指标速查表》预注册主指标，避免实验后按结果挑指标；
5. 每轮实验复制《实验结果记录模板》，记录数据版本、配置、重复次数、置信区间和失败样本；
6. 只有有日志、标注、脚本或输出文件支撑的数据，才可从教学算例改写为论文实验结果。

## 证据纪律

- `VERIFIED`：指标或实验要求已在本地笔记/研究计划出现，不表示其中的行业阈值已由原始文献核验。
- `INFERRED`：根据当前 CERA 研究问题推导出的建议指标。
- `UNVERIFIED`：存在经验阈值或说法，但尚未回到原始来源核验。
- `AUTHOR_INPUT_NEEDED`：需要作者根据任务、SLO 或标注协议作出决定。

另使用 A/B/C 来源等级：A 为论文原定义，B 为面向 CERA 的论文改造，C 为本课题新定义。该等级只表示定义来源，不表示实验已经完成。

官方文件另标记为 `STD-CURRENT`、`OFFICIAL-FRAMEWORK`、`STD-DRAFT` 或 `INDUSTRY-CONVENTION`；在研标准和公开草案不能表述为已经生效的要求。
