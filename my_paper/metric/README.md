# metric

本目录收录毕业论文中与多智能体 AgentOps、可观测性、故障归因和自治修复有关的评价指标。

## 文件说明

| 文件 | 用途 |
|---|---|
| [指标体系总览.md](指标体系总览.md) | 完整指标库。每个指标均包含定义、计算方式或判定口径、Agent 具体例子和论文用途。 |
| [核心指标速查表.md](核心指标速查表.md) | CERA 第一版实验建议优先报告的核心指标及对照关系。 |
| [实验结果记录模板.md](实验结果记录模板.md) | 实验运行、统计汇总和结论约束的可复用模板。 |

## 使用顺序

1. 先在《指标体系总览》中确认指标定义和适用范围；
2. 再用《核心指标速查表》选定主指标，避免实验后按结果挑指标；
3. 每轮实验复制《实验结果记录模板》，记录数据版本、配置、重复次数、置信区间和失败样本；
4. 只有有日志、标注、脚本或输出文件支撑的数据，才可从教学算例改写为论文实验结果。

## 证据纪律

- `VERIFIED`：指标或实验要求已在本地笔记/研究计划出现，不表示其中的行业阈值已由原始文献核验。
- `INFERRED`：根据当前 CERA 研究问题推导出的建议指标。
- `UNVERIFIED`：存在经验阈值或说法，但尚未回到原始来源核验。
- `AUTHOR_INPUT_NEEDED`：需要作者根据任务、SLO 或标注协议作出决定。
