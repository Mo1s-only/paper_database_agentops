# 实验与统计计划

## 1. 实验矩阵

维度包括：任务类型、Agent 数、trace 长度、故障类型、并发、预算、采样策略和信号组合。先用小型全量 trace 作为“可见上界”，再离线模拟不同采样方案；只有离线有效后才实现在线升档。

## 2. 基线

- Full：全量采集；
- App-only：只采 Agent/消息日志；
- System-only：只采进程/文件/网络；
- Fixed-p：固定比例采样；
- Random-budget：同预算随机采样；
- Rule-trigger：简单阈值升档；
- Proposed：学习或优化后的策略。

## 3. 主指标

- 诊断：Agent/Step/Edge F1、Hit@k、置信度校准；
- 证据：关键事件保留率、配对覆盖率、可重放率；
- 开销：端到端时延、P95/P99、CPU、RSS、存储、网络、token、费用；
- 隐私：原文暴露量、敏感字段保留率或脱敏失败率；
- 综合：质量—成本 Pareto 前沿，不只报告一个加权分数。

## 4. 实验阶段

1. 离线 replay：从全量 trace 模拟采样，排除系统实现噪声。
2. 在线 A/B：比较固定采样与自适应升档的真实性能。
3. 压力测试：并发、长 trace、突发故障和触发风暴。
4. 迁移：在未用于策略调参的框架/任务上测试。

## 5. 统计与停止条件

- 预注册预算档位和主要 Pareto 比较；
- 对配对任务做重复运行和 bootstrap CI；
- 报告尾延迟和最坏开销，不只均值；
- 若离线最优策略相对规则基线无稳定优势，不进入复杂在线学习；
- 若升档本身显著改变任务成功率，先修复观测者效应。
