# 方向 02：预算约束下的自适应可观测性

## 一句话定位

研究在时延、存储、隐私和 token 预算受限时，AgentOps 应该“记录什么、何时升档记录、保留多久”，使诊断信息损失最小而观测成本可控。

## 为什么适合当前仓库

- AgentSight 已能采集进程、文件、网络、工具、模型调用和资源信号，天然支持信号层消融。
- 当前 `orphan_response` 暴露了“观测并非天然完整”，可以从缺陷转化为证据质量研究问题。
- `my_paper/metric/` 已有观测开销、任务时延、成本、SLO、证据完整率等指标。
- 相比完整的因果归因，本方向不要求第一阶段就训练复杂诊断模型，可先用信息增益和分级采样完成系统贡献。

## 核心差异化

已有 AgentSight/eInfer/TELLER 关注非侵入采集或跨层诊断；本方向关注“可观测性预算分配”。核心不是采得更多，而是在错误风险变化时动态选择语义、行为和资源证据，并量化诊断效用损失。

## 预期贡献

- C1：Agent trace 的证据价值—成本模型。
- C2：常态低成本、风险触发升档的自适应采样策略。
- C3：缺失证据下的诊断可恢复性与置信度校准方法。
- C4：面向 Agent 工作负载的可重复观测开销与隐私评测。

## 对标类型与层次

- 主攻：Middleware、ISSRE（CCF B 类），适合系统/可靠性与成本权衡。
- 冲刺：ASE（CCF A 类），前提是策略能显著改善诊断且具备自动化方法创新。
- 期刊：JSS、IST、STVR（CCF B 类），适合更完整的系统实现与长期实验。
- 原型阶段：eBPF/Agent/observability Workshop，适合早期设计与工具展示。

## 当前成熟度

`INFERRED / 可快速做 pilot`。信号已经存在，但尚无分层采样器、预算策略和诊断效用曲线。

## Go / No-Go

- Go：在不显著降低归因/检测质量的情况下，至少一种开销维度形成稳定 Pareto 改善。
- No-Go：节省主要来自丢弃对诊断无影响的冗余日志，且策略无法跨任务迁移；此时降为工程优化或并入方向 01。
