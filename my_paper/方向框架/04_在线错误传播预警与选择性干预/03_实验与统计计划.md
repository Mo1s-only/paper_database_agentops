# 实验与统计计划

## 1. 实验环境

- 先在沙箱和可回滚任务上运行；
- 覆盖至少两类协作拓扑和多轮任务；
- 使用 AgentChaos 类 API 故障、工具静默错误、错误消息和资源异常；
- 另保留自然失败集，验证注入训练能否迁移。

## 2. 时间切片评测

对每个失败 run 在多个前缀 `t` 上预测，绘制性能—提前量曲线。不能只在完整 trace 上做“早期预警”。训练/测试划分按任务族或项目分组。

## 3. 基线与消融

- 无干预；
- 固定规则/阈值；
- 最后一步反应式检测；
- 不含图特征；
- 不含系统证据；
- 无拒绝动作；
- 删除整 Agent vs 边级局部干预；
- oracle 干预上界。

## 4. 主指标

- 预测：AUPRC、AUROC、Brier、ECE、lead time；
- 干预：任务成功增益、恢复率、误干预率、回归率；
- 过程：Progress Rate、错误传播边 Hit@k；
- 代价：额外 token、时延、费用、动作次数；
- 净效用：分别报告各项，再在敏感性分析中展示不同成本权重。

## 5. 安全与统计

- 对不干预/规则/主策略使用相同任务和随机种子或配对设计；
- 报告 bootstrap CI、效应量和故障类型分层结果；
- 对高风险动作只模拟，不连接真实外部系统；
- 若误干预造成的失败多于修复的失败，停止在线扩展并分析阈值/校准。
