# 实证研究框架

## 1. 概念模型

```text
系统/任务因素
  → 真实执行与失败
  → 可观测证据
  → 评价器/归因器
  → 指标数值
  → 研究者或开发者结论
```

研究重点是每个箭头可能引入的偏差，而不是默认指标等同于真实质量。

## 2. 变量分组

- 自变量：框架、模型、任务、拓扑、故障、证据层、judge、提示词、重复次数；
- 因变量：任务成功、Progress Rate、`pass^k`、Agent/Step/Edge F1、成本、调试用时；
- 控制变量：温度、版本、任务判据、最大步数、工具权限、环境状态；
- 随机效应：任务、项目、模型、运行批次、标注者。

## 3. 指标质量维度

- 内容效度：是否覆盖研究对象的重要方面；
- 收敛效度：相关指标是否在应相关处一致；
- 区分效度：不同概念是否没有被同一个分数混淆；
- 信度：重复运行、重标注和换 judge 后是否稳定；
- 校准：置信度是否对应真实正确率；
- 可操作性：是否帮助定位、修复或选择系统。

## 4. 数据处理原则

- 所有派生指标保留分子、分母和排除原因；
- 不把不同任务的任意分数直接平均，先做任务内归一化或分层模型；
- 相关不等于可替代，排名一致不等于数值一致；
- 缺失数据报告机制，不能默认缺失为 0；
- 指标选择和主比较在看结果前预注册。
