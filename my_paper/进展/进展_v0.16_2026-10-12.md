# AgentOps 研究进展 v0.16（2026-10-12）

## 本阶段结论

当前状态可表述为：`VERIFIED_SINGLE_REAL_V0_2_EVENT_CHAIN`。单个真实 Claude Code 会话已经贯通“框架原生生命周期 → 共享工具 ID → AgentSight 工具记录 → 双 PID 证据 → 原始 boot 时钟换算 → 六事件协议 v0.2”。这证明采集与规范化链路在一个真实样本上可工作，还不能推出它在多 Agent、长会话或不同工具上的稳定性。

## VERIFIED

- `experiment_20261010_15` 真实会话一次成功，费用 0.024867 USD。纳秒级 boot epoch 修复使进程开始时间直接落入应用 Popen 边界，追加校正量为 0；但 SSE 工具时钟字段为空，因此该次实验只记为部分成功。
- SSE 聚合器现已透传时间归一化器写入的 `_agentsight_clock`。修复后的 AgentSight 1.0.31 release 二进制 SHA256 为 `6ef1946310895168c5df6b57addf8622725d45dc579c6a91e0fe441812d4211c`。
- 修复前本地验证通过：Trace Adapter 57 项 Python 测试、AgentSight analysis 128 项测试及 2 项文档测试、核心时钟 4 项测试。成本台账新增的去重测试 1 项通过；相关验证合计 192 项通过。
- `experiment_20261012_14` 只进行 1 个真实 API 会话且未重试。原生 init、tool_use、tool_result、result 各 1 条，生命周期闭合；共享 tool_call ID 在 AgentSight 中唯一命中。本次费用 0.024832 USD。
- 进程采样 522 次，覆盖 21 个唯一后代 PID。应用 PID 为 81，AgentSight 观测器 PID 为 1758；观测器 PID 不出现在应用容器的 `/proc` 视图中。
- realtime-monotonic 配对偏移范围宽度为 28950 ns。进程开始时间 1791785496876 ms 落在 Popen 区间 1791785496874.819–1791785496876.4282 ms 内，追加校正量为 0。
- 工具记录保存了原始 boot 时间 `154499649757 ns`、boot epoch `1791785365750464700 ns` 和锚点字段；epoch 公式可以精确复算。原生 tool_result 接收与 AgentSight 工具时间相差 1115.793 ms，对应单调钟差值 1115.678454 ms。
- 协议 v0.2 生成 6 条事件、1 个完整闭合 session，并通过严格读取校验。原始事件文件 SHA256 为 `f9fb7a628866c127f27749d95b582e4697cd3ce133f7eade7a16aa572a5c47b0`。
- 成本脚本已改为按 provider session ID 去重并保留重复路径。全仓扫描得到 30 次唯一计价运行、1 份重复 session 记录，累计 2.183708 USD。

## INFERRED

- 应用 PID 81 与观测器 PID 1758 的对应关系由相同 session、`claude` 进程名、启动区间和共享 tool_call ID 联合支持。当前没有能在两套 PID namespace 间直接进行数字换算的证据。
- `tool_result` 接收时间与系统工具时间的差值包含工具执行、CLI 处理和流式传输，不能作为单纯的观测延迟。
- `experiment_20261010_15` 的空工具时钟字段由 SSE 未透传 `_agentsight_clock` 导致；源码路径和修复后真实成功共同支持该解释，但没有逐个中间事件的独立外部探针。

## UNVERIFIED

- 双 PID 映射在多 Agent、多工具、长会话和异常退出场景中的稳定性。
- SSE 工具事件的精确生成点，以及各处理阶段分别贡献的端到端时间误差。
- 本次 `observer_clock_uncertainty_ns=0` 只是配对读取 bracket 的记录值，没有包含计时器分辨率下界，因此真实不确定度并未被证明为 0。
- 现有六事件链是否足以稳定生成可用于归因的 provenance graph 和 responsibility graph。

## 成本范围修正

调用前使用的 1.626016 USD 是旧范围台账。实验后扩大本地日志扫描范围，发现其中漏计 4 个历史唯一会话，共 0.5328595 USD；另有一份日志属于同一 session，已去重。按相同口径回算，本次调用前全仓累计实际已经是 2.158876 USD，本次新增 0.024832 USD 后为 2.183708 USD。该差异来自历史扫描范围不足，不是本次重复调用。

因此 2.00 USD 硬停止线现已触发。后续不再调用真实 API，也不进入新的多 Agent 在线实验。

## 下一研究闸门

下一阶段只使用已经采集的真实数据和合成输入：

1. 在时钟锚点不确定度中加入 `clock_getres` 或等价的计时器分辨率下界，避免 0 ns 被误读为零真实误差，并用本地测试验证。
2. 对 `experiment_20261012_14` 的原始 v0.2 事件做离线回放，生成带来源引用的 provenance graph，再基于显式规则生成 responsibility graph。
3. 用已有的成功、错误传播和路由错误记录验证图构建器的缺失证据处理；不能确定责任时必须输出 `unknown` 或 `abstain`。
4. 只有在未来重新批准预算且离线图构建门通过后，才考虑多 Agent 在线稳定性实验。

闸门通过条件是：图中每条节点和边都能回指原始事件；双 PID 映射持续标为推断；时钟不确定度有非零分辨率下界；对缺失 AgentSight 工具事件能够拒绝给出完整归因。
