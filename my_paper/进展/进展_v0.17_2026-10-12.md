# AgentOps 研究进展 v0.17（2026-10-12）

## 本阶段结论

在不增加 API 成本的前提下，事件规范化、跨层身份表示和时钟统一模块完成了一轮更严格的组件质量收口。当前标签为 `OBSERVATION_COMPONENT_READY_WITH_WARNINGS`：实现与负向验证没有阻塞性失败，独立 PID 真值和新时钟下界的在线验证仍缺失。

## VERIFIED

- boot epoch 锚点不确定度已加入 `CLOCK_REALTIME`、`CLOCK_MONOTONIC` 分辨率和 1 ns 的非零下界。
- AgentSight capture 44 项库测试通过、0 项失败、1 项环境测试忽略；其中 5 项时钟测试通过。
- 新 release 构建成功，AgentSight 版本 1.0.31，SHA256 为 `70c839ba59ff8c1bbf679e4258b6fa019fb7f6bec625d4e7f0885768b3c3134f`。
- Trace Adapter 测试由 57 项增加到 64 项，全部通过。
- 协议事件 ID 改为稳定 UUID5；同一真实输入两次独立回放输出字节一致，输出 SHA256 均为 `ba8a8dd6e42706c58710e96a553f3db5e142d5ec0f9127655cd8331c3b37d06f`。
- 8 类无效输入全部被拒绝，包括身份变化、生命周期缺失、时钟公式错误和字段不完整。
- PID 映射覆盖率按 session 报告：accepted=0、inferred=1、abstain=0；准确率状态明确为 `UNVERIFIED_WITHOUT_INDEPENDENT_PID_GROUND_TRUTH`。
- 本地受控 PID namespace 成功产生直接真值：外层观测 PID=13、内层 PID=1、`NSpid=[13, 1]`，该夹具映射标为 accepted。
- 本轮网络/API 调用数为 0。

## INFERRED

- 现有真实会话的双 PID 关系仍是有多项证据支持的推断，而非直接 namespace 真值。
- 现有结果足以把观测模块作为论文中的方法实现和真实可行性案例，但不能支持通用稳定性结论。

## UNVERIFIED

- 新 release 尚未产生新的真实工具事件，因此非零时钟下界目前只有源码测试证据。
- 尚未得到真实 Claude PID 81 与 PID 1758 的独立 namespace 映射真值；直接真值只覆盖本地夹具，因此真实会话仍无法报告 Precision/Recall。
- 尚未覆盖另一种 Agent 框架、内核或机器环境。

## 下一组件闸门

继续保持零 API：下一步将受控 namespace 夹具扩展为多个并发进程、PID 冲突和缺失 `NSpid` 场景，分别验证 accepted、inferred 和 abstain 决策；真实 Claude 历史事件仍不补造不存在的 NSpid 证据。
