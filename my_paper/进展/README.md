# AgentOps 研究进展

本文件夹按“进展 + 版本 + 时间”保存阶段性研究记录。每个版本只记录当时已经完成、正在推断和仍需验证的内容，不把计划写成结果。

当前主线：

```text
Agent 运行观测 → 故障归因 → 根因诊断/定位
```

预测与早期预警暂作为扩展方向，只有在观测和定位链路形成可靠数据与标签后再决定是否纳入核心贡献。

版本约定：

- `v0.x`：方向梳理、文献证据和实验协议阶段；
- `v1.x`：完成可运行原型和第一轮可复现实验；
- `v2.x`：完成对照、消融、误差分析和论文级证据。

当前最新记录见同目录下按日期命名的进展文件。
