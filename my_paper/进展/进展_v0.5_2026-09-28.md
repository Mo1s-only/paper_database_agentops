## 3. 为什么现在先做成本控制

当前最缺的不是更多单次运行，而是可审计的真值、反事实协议和证据消融。若在 schema 尚未冻结时直接跑 30–50 次真实 Agent，成本会增加，但不能提高论文证据质量。先用零 API 的确定性 harness 固定协议，再用最小真实批次验证，是当前风险最低的路线。

## 4. 下一轮真实实验策略

采用分阶段预算：

1. **预检阶段**：0 次 API，检查 schema、脚本、真值和预算；
2. **最小真实 pilot**：三类故障各 1 次，预计 3–6 次 API 调用；
3. **扩展阶段**：只有三类 pilot 都满足 AgentSight 非零观测、独立真值和反事实复验，才考虑扩展到 30–50 条。

每次真实运行必须保存：`session.db`、`raw-stream.log`、`trace.jsonl`、`ground_truth.json`、`analysis.json` 和 `cost.json`。
