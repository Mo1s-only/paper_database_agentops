## 3. 框架原生事件实测

### VERIFIED

- 1/1 个真实 API 会话成功，报告费用 0.024657 USD；累计本地 CLI 报告费用更新为 **1.601149 USD**。
- Claude 原生流观察到 init、tool_use、tool_result、result 各 1 条，工具生命周期闭合。
- 同一 tool_call ID 在 AgentSight `tool_calls` 唯一命中，工具捕获为 1/1。
- 共取得 620 次进程/时钟采样，覆盖 18 个应用命名空间唯一 PID。
- 应用侧 Claude PID 为 81，工具自报 PID/PPID 为 171/169；AgentSight 的 Claude/HTTP PID 为 341。341 不存在于应用侧挂载的 `/proc` 视图。
- 620 次 `realtime - monotonic` 锚点范围宽度为 30 微秒，本次进程内墙钟—单调钟配对稳定。
- 本地 AgentSight 源码使用 `bpf_get_current_pid_tgid` 采集 PID，并将 `bpf_ktime_get_ns()` 加到整数秒 boot epoch。按实测锚点，本次整秒转换缺失 413.555968 ms。
- 加回该差值后，AgentSight Claude 进程开始时间为 1791615126130.556 ms，位于 Popen 的 1791615126129.423–1791615126130.928 ms 边界内。
- 原生 tool_result 接收时间减原始 AgentSight 工具时间为 1542.488 ms；去除整秒转换误差后为 1128.932 ms。

实验报告：[experiment_20261010_14/实验报告.md](../../lab/experiment/experiment_20261010_14/实验报告.md)。

## 4. INFERRED

- session ID、`claude` 进程名和校正后启动区间共同支持“应用 PID 81 与 AgentSight PID 341 是同一进程的不同 PID 命名空间视图”。当前 `/proc` 挂载没有提供 81→341 的直接数字映射，因此该关系仍标记为推断。
- 413.555968 ms 可以解释当前 boot 内 AgentSight 的整秒 epoch 转换偏差；它必须每次启动重新测量，不能跨 boot 复用。
- 校正后剩余的 1128.932 ms 包括工具执行、模型/CLI 处理和流式事件抵达时间，不是单纯时钟误差。
