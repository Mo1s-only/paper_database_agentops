# 进展 v0.20（2026-10-13）

## 本阶段研究决定

归因前身份链不再接受“session + 进程名 + 启动区间 + tool_call ID”作为最高等级证据。AgentSight 已能在进程 EXEC 事件中直接输出 initial PID namespace TGID 和采集器指定 PID namespace TGID；只有唯一直接映射才标为 `accepted`，多候选或字段缺失时保持 `inferred/abstain`。

## VERIFIED

- 本地真实进程事件获得 `initial_pid=1791`、`namespace_pid=34`、`userspace_pid=34`。
- 直接证据为 `bpf.pidns.tgid=1791,34`，来源是 `bpf_get_ns_current_pid_tgid`。
- 时钟锚点的不确定度下界为 1 ns，原始 boot time 与 boot epoch 锚点均已保存。
- BPF runtime 7/7、Trace Adapter 101/101 测试通过。
- 统一事件 v0.2 已接受两类直接身份依据：`/proc/status` 的 NSpid 向量和 BPF 指定 namespace TGID；证据格式与方法不匹配会被拒绝。
- 新增控制式模型调用上下文采集：请求前冻结模型 ID/版本、temperature、top_p、system prompt 哈希、tool schema 哈希和单调时钟；响应后绑定 provider response ID。原文不进入 sidecar。

## INFERRED

- 历史真实会话中应用 PID 与 AgentSight PID 的间接映射，现在有了可替换的直接机制；仍需在新的真实 API 会话中验证端到端写库和统一事件生成。

## UNVERIFIED

- 双 Agent 并发、进程重启、PID 重用和长会话条件下的直接映射准确率与覆盖率。
- 控制式模型调用上下文在真实 provider API 返回字段上的完整性。
- 严格时间偏序在多主机或多容器环境中的误差界。

## 成本状态

计划执行两个真实 CLI 会话，每次最坏 0.05 USD。成本台账已累计 2.183708 USD，预计总额 2.283708 USD，超过现行 2.00 USD 硬停止线，因此本轮没有进行网络调用。

## 下一研究闸门

提高成本硬上限后执行两次受控真实会话，并要求每个会话同时具备：

1. 唯一直接 PID namespace 映射；
2. 非零时钟不确定度下界；
3. 完整且可校验的模型调用上下文；
4. 每条观察关系对应可重放查询收据。

四项全部通过后，才能把“归因前观测链已经闭合”作为论文实验结论；这仍不等于归因方法本身已经完成。
