# 公开数据集小样本适配性检查（2026-10-22）

## 本轮目的和边界

从本地 `Reference paper/datasets` 选取少量、标签形态互补的数据，检查 Adapter 周边是否能稳定读取其结构并保留标注来源。原数据目录只读；输出只包含 5 个样本的精简标签/结构清单与哈希，不复制完整对话正文。

请求中写的 `C:\Users\mobao\Desktop\论文方向\Reference paper\datasets` 在本次执行环境不存在；实际使用的是当前仓库里的同名资料夹 `C:\Users\Administrator\Desktop\论文方向\Reference paper\datasets`。

**这不是端到端 AgentSight/eBPF 泛化实验。** 所选公开文件是轨迹或归因标注，不包含本项目采集时生成的 Claude 原生 `tool_call_id`、AgentSight SQLite 工具行和 eBPF PID 谱系。因此，本轮可以验证跨数据集字段兼容、标签溯源和能力边界；不能验证工具 ID→PID 关联成功率、根因准确率或 AgentSight 捕获率。处理结果把 runtime evidence 显式置为 `null`，防止将论文标注误并为运行时观察。

## 选取的 3 个数据集、5 个实例

| 数据集 | 抽取实例 | 可提供的标签/结构 | 缺少的关键运行时字段 | 适用验证 |

原始数据来源及固定版本/目录哈希见 [datasets README](../../Reference%20paper/datasets/README.md) 与 `manifest.json`。本次选中样本和其 SHA-256 在 `subset-manifest.json`；规范化后的少量字段在 `selected-cases.jsonl`。

## 排除项

- MultiAgentBench 本地快照是任务配置，不是运行轨迹/根因标签；执行还需要 Minecraft 等环境、完整 runner 和模型配置，暂不把“能读 YAML”混作跨层归因验证。
- EIB/AutoForm 快照主要用于推理/格式任务，当前没有本实验所需的 Agent-step 或错误依赖标注，不进入这一小批。
- 暂不扩展到 4–5 个来源：AgentTrace、Who&When、TRAIL 已覆盖图结构、Agent/step 标签和 span 多错误三类关键标签形态。

## 本轮验证

- `prepare_public_dataset_subset.py` 对上述 5 个样本完成解析并生成源文件/成员 SHA-256；对 AgentTrace root/path 引用做存在性检查，对 Who&When 的 attribution 字段做完整性检查，对 TRAIL 的多错误字段做完整性检查。
- 新增两个测试：5/5 样本规范化成功；所有 runtime evidence 均保持空值；既有输出目录拒绝覆盖。全量 `trace_adapter` 回归 131/131 通过，Windows 并发 hook JSONL 测试额外连续复跑 5/5 通过。此结果仅代表解析/溯源契约通过，不是数据链捕获率或归因准确率。
- 费用/API 调用：0。

## 下一道研究关口

要验证论文主张的“语义层+AgentSight/eBPF 系统层”在公开数据上的端到端泛化，需为选中的样本先定义可执行任务重放方式，再让 Agent 重新执行并独立采集 runtime trace；原论文的历史对话/标注不能直接提供这次新运行的 PID 和工具 ID。需把每轮重放和原始 gold label 分开保存，且仅在采集结束后评估标签映射。优先从 Who&When 的短 Algorithm-Generated 样本和 AgentTrace 中能确定脚本/工具步骤的场景挑可执行子集；TRAIL 更适合离线评估 span 错误标签映射，SWE-bench 任务的真实执行环境与成本应单独评估。只有这一步完成，才可报告跨数据集运行时关联覆盖率或 attribution 指标。
