# AgentSight 本地 HTTPS/SSE Loopback 复测

**日期**：2026-10-21  
**性质**：零成本本地 mock；不是真实供应商调用  
**结论**：当前安装版 AgentSight 能从当前 Claude Code 进程捕获一次本地 Anthropic 兼容流式请求并生成 LLM/token 记录；真实 DeepSeek 语义缺失因此不是“当前 Claude 版本下 AgentSight 完全不能采 SSL/HTTP”的证据。

## 配置与结果

使用 Claude Code `2.1.303`、AgentSight `1.0.31`，隔离 HOME、假 API key 和 `127.0.0.1` TLS mock；没有读取真实凭据，也没有访问外部模型端点。CLI 成功，mock 收到 1 个请求，路径为 `/anthropic/v1/messages`，请求体 10,840 bytes，`stream=true`。AgentSight 数据库为 `llm_calls=1`、`token_usage=1`、`network_targets=1`、`tool_calls=0`。

日志同样出现 `SSL_write` 符号缺失和 BoringSSL offset fallback，但这次仍捕获到语义行。因此该 warning 本身不能证明探针完全失效。该 mock 没有返回 `tool_use`，所以 `tool_calls=0` 不用于判断工具解析能力。

注意：虽以 `--h2` 启动了支持 HTTP/2 ALPN 的 mock server，mock 实际记录的协议为 HTTP/1.1；本次结果**不能作为 AgentSight HTTP/2 捕获通过**。

## 与真实 DeepSeek 失败的差异

当前真实实验有 DeepSeek host/path 和对应 Claude PID，但 `llm_calls=0`。本地 mock 则在同一 CLI/AgentSight 版本下捕获到有请求体的 SSE 请求。结合源码中 body/model 均缺失时原先会丢弃 LLM 请求、工作树现有补丁改为低置信度保留的逻辑，真实请求体未被重建或安装二进制未包含该补丁，是优先验证的候选原因；仍需原始 HTTP 事件确认，不能写成已证实根因。

## 证据状态与下一步

- **VERIFIED**：当前安装版可捕获这个本地 HTTP/1.1 SSE 请求；没有调用付费 API。
- **INFERRED**：实际 DeepSeek endpoint/响应路径与 mock 有差异，或真实请求在 HTTP 重建时缺少可解析 body；仅凭 network target 无法区分。
- **UNVERIFIED**：HTTP/2、真实 DeepSeek 请求体/响应 SSE 是否进入 parser，工具调用响应是否能被提取。
- **后续进展（2026-10-21）**：本地 thesis_adapter checkout 缺少 collector 的 `output` Rust 模块；从同版本 AgentSight `1.0.31` 源码恢复 `format.rs`、`tui.rs`、`mod.rs` 后，全量 CLI 离线 release 构建通过。候选二进制在隔离 loopback mock 下也捕获到 `llm_calls=1`、`token_usage=1`、`network_targets=1` 和进程审计数据。由于已安装版此前也捕获到同类完整请求，这只能验证候选构建可运行、无明显回归，不能证明 bodyless-request 补丁解释了真实 DeepSeek 的缺失。

真实 API canary 的只读预检停止在凭据检查：WSL root 没有 `ANTHROPIC_*`/`DEEPSEEK_*` 环境变量或 Claude 凭据文件，Windows 用户环境与常见 Claude 凭据文件位置也未发现凭据。这里的 `ANTHROPIC_*` 是 Claude Code 调用 Anthropic 兼容 API 时使用的客户端变量名；provider 仍须配置为 DeepSeek。此次没有发出真实 API 请求。详细结果见 [`候选构建与真实 API 预检报告`](../experiment_20261021_24_agentsight_candidate_mock/实验报告.md)。

下一闸门：为 Claude Code 安全启用 DeepSeek 兼容 API 所需凭据后，先重跑单次预算预检，再用候选二进制做一次真实 API canary；另外补齐 bodyless/full-body、实际 HTTP/2 和 tool-use SSE 的零成本差分。当前 mock 未覆盖后面两类链路。
