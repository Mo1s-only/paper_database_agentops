# 公开数据集适配与 TRAIL 原始 trace 连接复核（2026-10-22）

## 本轮目的

在先前 3 个数据集家族、5 个样本的只读结构检查上，进一步验证 TRAIL 的错误标注能否通过 `location` 精确落到其随附历史语义 trace 的 `span_id`。原始数据集保持只读；旧报告与旧输出目录未覆盖。新版结果由 `prepare_public_dataset_subset.py` 生成于本目录。

## 结果

| 数据集样本 | 错误标注数 | 原始 trace span 数 | `location == span_id` | 结果 |
|---|---:|---:|---:|---|
| TRAIL / GAIA `0035f455b3ff2295167a844f04d85d34` | 3 | 11 | 3/3 | 全部精确解析 |
| TRAIL / SWE-bench `0e6f7928953ab5a568bae640ce915cc3` | 8 | 32 | 8/8 | 全部精确解析 |

程序递归读取原始 trace 的根 span 和 `child_spans`，构造 `span_id` 集合，再与每条 gold error 的 `location` 做精确字符串比较。另一个独立规范化器将两个样本的所有 43 条 span（GAIA 11 条、SWE-bench 32 条）映射成 `public.semantic_span` JSONL 记录，**43/43 均被保留**。规范化记录保留 trace/span/parent ID、时间、duration、span 名称、服务名、OpenInference 类型、工具名/模型名和来源 SHA-256；不复制 prompt/completion/工具参数或输出正文。错误标签与语义观察分别落在 `selected-cases.jsonl` 和 `trail-normalized-spans.jsonl`，没有把 gold label 混入观察事件。

两个样本的原始 trace 包含 `LiteLLMModel.__call__` 的 OpenInference 输入/输出属性，以及 `FinalAnswerTool` 等 span；它们是原论文数据中的历史语义/应用 trace。因此本次新增证据是“错误标注 → 历史语义 span ID”的直接结构连接，而不是仅仅把错误字段读入 JSON。

## 正式 Adapter 入口门禁

将 43 条规范化记录送入现有 `align_candidates.load_evidence` 正式证据入口进行门禁检查，结果为 **admitted 0 / excluded 43**，拒绝原因是 `not_observed_or_not_allowlisted`。这是预期的 fail-closed 结果：该入口只接受本项目当前运行中 `evidence_status=observed` 且来源角色为 `raw_observation` 或 `app_log` 的证据；TRAIL 记录标为 `historical_public_trace`，表示另一篇工作的历史语义 trace，不得作为本项目当前运行的 AgentSight/eBPF 观测输入。

因此，本阶段验证到 Adapter 边界为止：公开 trace 的专用规范化与 gold-location→span 对齐成立，但它**不能通过运行时跨层归因入口**，也不应通过放宽运行时准入条件来“接通”。为纳入公开数据集结构兼容评估，已新增隔离的 public-trace/label-mapping evaluator，未改写 `align_candidates` 的 observed-only 策略。

## 独立公开标签映射评估器

已新增 `evaluate_public_dataset_mapping.py`，作为与运行时归因入口隔离的 evaluator：读取 5 个选中样本和 43 条规范化 TRAIL span，重新校验每个原始 artifact 与选中记录的 SHA-256，再按数据集标签形态做直接解析。最新结果见 `public-label-mapping-evaluation-v3.json`，对 5/5 个原始 artifact 和选中记录重新校验 SHA-256：

- AgentTrace：根因节点、错误节点均存在；因果路径 3/3 节点和 2/2 边可解析。
- Who&When：两条样本的 4/4 gold 字段均存在；但 `mistake_step` 未能连接到 history 中的稳定 turn/step ID，因此只计为“标签存在”，不计作 step 对齐成功。
- TRAIL：GAIA 3/3、SWE-bench 8/8 gold location 均命中规范化 span ID。

该 evaluator 测试的是**标签结构/位置可解析性**，不是模型推断或归因效果，也不把不同数据集的指标合并成一个虚假的准确率。

## 证据边界

- **VERIFIED**：所选 GAIA 3 条和 SWE-bench 8 条标注全部精确指向相同 ID 的原始 trace span；该小样本连接率分别为 3/3、8/8。
- **VERIFIED**：原始 span 结构中可见 LLM invocation 与工具 span，且存在 span ID、父子层级、时间戳和 duration。
- **VERIFIED**：该 TRAIL 样本 schema 没有本项目的 Claude 原生 `tool_call_id`、AgentSight SQLite 工具记录、OS PID/PPID 或 eBPF 事件；新版记录仍将 `runtime_evidence` 留空。
- **INFERRED**：TRAIL 可以用于检验 Adapter 对 OpenInference/历史语义 trace 的解析及其错误位置定位能力；这有望作为跨来源的语义层兼容性实验。
- **UNVERIFIED**：Adapter 尚未把这 43 个原始 spans（GAIA 11 + SWE-bench 32）完整转换为本项目统一事件 schema，也未测量字段完整率、解析失败率或根因排序效果。
- **UNVERIFIED**：这不是新的 Claude/AgentSight/eBPF 采集，不能说明当前运行中工具调用与系统进程已跨层关联，也不能据此报告端到端泛化或归因准确率。
