# 实验记录目录

从 2026-10-10 起，论文实验统一在本目录登记。一级目录名称固定为：

```text
experiment_YYYYMMDD_HH
```

其中时间使用 Asia/Shanghai 时区并精确到小时。同一小时存在多次运行时，统一登记在该小时目录的 `runs.json` 中，避免为了区分运行而破坏目录命名格式。

每个目录至少保存：

- `README.md`：目的、方法、结果和证据边界；
- `plan.json` 或 `runs.json`：机器可读计划/运行索引；
- 可提交的汇总结果；
- `results/`：原始日志、SQLite、JSONL 等本机数据。该目录默认受 `.gitignore` 保护。

历史实验不移动原始文件，只登记原始路径和时间证据。总索引见 [experiment_index.json](experiment_index.json)。
