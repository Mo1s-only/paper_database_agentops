# 第 5 章练习与验收

## 练习

1. 用同一任务设计 pipeline、supervisor、debate、shared-workspace 四种架构。
2. 对每种架构列出消息数、模型调用数、关键路径、单点故障和验证节点。
3. 注入一个错误消息，画出它在四种拓扑中的传播路径。
4. 为 handoff 定义契约：目标、上下文、已完成工作、未决风险和验收条件。

## 验收问题

- 多 Agent 的“更多视角”何时变成更多噪声和成本？
- 通信图和因果图为什么不能直接等同？
- 如何区分节点冗余与边冗余？
- 共享工作区如何导致竞态和错误覆盖？

产物：四种拓扑比较表 + 一张错误传播图 + handoff 契约。
