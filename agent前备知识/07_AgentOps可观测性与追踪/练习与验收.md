# 第 7 章练习与验收

## 练习

1. 选择一个任务，分别设计应用日志、OTel trace 和系统边界事件。
2. 把三层事件映射到同一 `run_id/agent_id/step_id/call_id`。
3. 删除 10%、30%、50% 事件，记录哪些诊断问题变得不可回答。
4. 估算全量记录的时间、存储、Token 和隐私成本。

## 验收问题

- 可观测性与监控有什么差别？
- Span 的父子关系等于因果关系吗？
- eBPF 能看到什么，为什么仍有语义鸿沟？
- 为什么 `orphan_response` 不能作为完整 LLM 调用样本？
