# 第 2 章练习与验收

## 练习

1. 对同一提示运行多次，记录模型版本、参数、输出、Token 与延迟，观察变异。
2. 设计一个 JSON schema，故意制造缺字段、类型错误、截断和多余文本四种失败。
3. 为同一输出设计“规则判定、LLM judge、人工判定”三种评价，比较分歧。
4. 把一个自然语言中间消息改成结构化格式，记录 Token 与解析成功率。

## 验收问题

- 为什么固定 Prompt 仍不能保证固定输出？
- Prompt、上下文、记忆和模型内部参数有什么区别？
- Judge 分数何时只能算代理指标？
- Token 下降为什么不一定代表系统成本下降？

产物：一次小型重复实验记录 + 一张模型失败与 Agent 失败的判别表。
