# 十二周学习计划

建议每周 6–10 小时。每周必须交付一个可检查产物；若时间不足，减少阅读量，不取消产物。

| 周 | 主题 | 必读章节 | 最小产物 |
|---:|---|---|---|
| 1 | 系统基础与运行证据 | 01 | 画出一次 Agent 任务的进程、文件、网络和数据库证据流 |
| 2 | LLM 调用与不确定性 | 02 | 解释 Token、上下文、采样、缓存与结构化输出失败 |
| 3 | 单 Agent 执行循环 | 03 | 为一个工具 Agent 画状态机和事件表 |
| 4 | 工具与协议 | 04 | 写出一个工具契约及其权限、错误和审计字段 |
| 5 | 多 Agent 协作 | 05 | 比较 supervisor、pipeline、debate、shared-workspace 四种拓扑 |
| 6 | 故障分类与传播 | 06 | 标注 10 条失败轨迹的故障类型和传播路径 |
| 7 | AgentOps 观测 | 07 | 设计统一事件 schema，并说明每个字段从哪里采集 |
| 8 | 归因与根因诊断 | 08 | 对一条失败 trace 生成 Agent/Step/Edge 候选与反事实计划 |
| 9 | 评测与统计 | 09 | 写出主指标、基线、重复次数、置信区间与停止条件 |
| 10 | 安全与治理 | 10 | 完成一次 trace 数据威胁建模和脱敏清单 |
| 11 | 本项目复现 | 11 | 查询真实 `session.db`，产出一页证据链报告 |
| 12 | 论文衔接 | 12 | 完成最小 RQ、贡献、实验矩阵和 Go/No-Go 判断 |

## 每周节奏

1. **概念（20%）**：阅读本章 README，补齐术语。
2. **项目材料（30%）**：只读本章列出的高优先级文件。
3. **动手（40%）**：完成图、表、代码或实验。
4. **复盘（10%）**：记录仍不确定的主张和下一道研究闸门。

## 三次阶段验收

### 第 4 周：能解释 Agent

- 能区分模型调用、Agent 步骤、工具调用和环境副作用；
- 能说明 MCP/工具协议与 Agent 本身不是同一层；
- 能给一次任务定义稳定的 run、agent、step、call 标识。

### 第 8 周：能诊断 Agent

- 能区分异常检测、故障归因、根因诊断和自动修复；
- 能把事件组织成 Agent—Step—Tool—Outcome 执行图；
- 能提出可执行的反事实，而不是只让 LLM 猜根因。

### 第 12 周：能设计论文实验

- 有明确 RQ、对象、干预、测量、基线和边界；
- 真值、故障注入、排除规则和统计方法可复现；
- 区分已有 demo、方法原型和论文级有效性证据。
