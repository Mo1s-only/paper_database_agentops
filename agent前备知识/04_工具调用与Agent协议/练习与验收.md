# 第 4 章练习与验收

## 练习

1. 设计一个“写文件”工具的 JSON schema、成功返回和六类错误返回。
2. 为超时重试设计幂等键；说明无法幂等时如何补偿。
3. 用表格区分 Function Calling、MCP Tool、Skill、Plugin 和 Agent。
4. 为一个 MCP server 画信任边界：客户端、传输、服务进程、资源和外部网络。

## 验收问题

- 工具返回 200/成功为什么不等于任务成功？
- 显式错误和静默错误分别如何检测？
- 工具调用的意图、执行和副作用应怎样关联？
- 哪些工具必须增加人工确认或沙箱？

产物：工具契约文档 + 威胁模型 + 一组失败测试。
