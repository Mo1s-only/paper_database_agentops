## 4. 阅读顺序原则

1. 先读项目整理文档，再读精读笔记，最后查原论文。
2. 先明确论文解决的问题和证据，再记方法名或数字。
3. 对关键数值回到 PDF/原始实验，不把二手总结当最终引用。
4. 上游设计文档可用于理解方案，但其中的设想、市场判断和未复验案例不能自动视为本项目结果。
5. 源码 README 用于实现细节；论文主张仍需实验结果或正式文献支撑。
