# 核心术语表

| 术语 | 工作定义 | 容易混淆的概念 |
|---|---|---|
| Agent | 以目标为导向，基于状态选择动作并通过工具/环境形成闭环的执行主体 | 单次 LLM 调用、固定工作流 |
| Agentic workflow | 含模型决策的工作流，自主程度可以很低 | 完全自治 Agent |
| Run | 一次端到端任务执行实例 | session、step |
| Session | 按用户、进程或时间组织的一组交互；边界依系统定义 | run |
| Step | 一次可解释的状态转移或决策单元 | model call、tool call |
| Model call | 一次模型请求与响应 | Agent step |
| Tool call | 一次工具请求、执行和返回 | 模型声明的调用意图 |
| Observation | 环境或工具返回给 Agent 的反馈 | trace 全部事件 |
| State | 决定后续动作的当前信息集合 | memory、context |
| Context | 当前模型调用可见的输入 | 长期记忆 |
| Memory | 可跨步骤或运行保存、检索和更新的信息机制 | 对话历史 |
| Handoff | 一个 Agent 将任务、上下文和责任转交给另一个 Agent | 普通消息 |
| Topology | Agent 节点及其通信/控制连接方式 | 因果图 |
| Event | 某时刻或区间发生的可记录事实 | log 文本行 |
| Log | 面向离散事件的记录 | metric、trace |
| Metric | 随时间聚合的数值信号 | 单个事件 |
| Trace | 一次执行跨组件的关联事件集合 | 单个 Span |
| Span | Trace 中有开始/结束和属性的操作区间 | step；二者不必一一对应 |
| Schema | 事件字段、类型和约束的统一定义 | 具体数据实例 |
| Instrumentation | 在代码或运行环境加入采集点 | 可观测性本身 |
| OpenTelemetry | 统一采集、传播和导出 traces/metrics/logs 的规范与生态 | 具体后端产品 |
| eBPF | 在 Linux 内核安全执行观测/控制程序的机制 | 高层 Agent 语义 |
| Boundary tracing | 在网络、TLS、进程、文件等稳定边界观察行为 | 应用框架插桩 |
| Observability | 依据外部信号理解系统内部状态的能力 | Dashboard、监控告警 |
| AgentOps | Agent 全生命周期中的观测、评价、治理和运行改进实践 | 仅日志平台 |
| Fault | 潜在原因或缺陷 | error、failure |
| Error | 系统内部的错误状态 | 外部可见 failure |
| Failure | 系统未满足预期服务或任务要求 | 单条异常日志 |
| Silent error | 表面成功但返回内容或副作用错误 | 显式异常 |
| Attribution | 判断哪个 Agent/步骤/边对失败有责任 | 异常检测、根因诊断 |
| Root cause | 若被修复/移除可阻止或显著改变失败的关键原因 | 最早异常、最后错误 |
| Causal graph | 表达变量或事件因果假设的图 | 调用图、依赖图、通信图 |
| Counterfactual | 在明确干预下比较“若改变某因素会怎样” | 语言模型猜测 |
| Replay | 使用保存输入和环境重新执行全部或局部过程 | 简单重试 |
| Ground truth | 用于评价的可信标签或可执行判据 | LLM judge 输出 |
| Baseline | 用于比较的已有或简化方法 | 旧版本随意结果 |
| Ablation | 移除/替换关键组件以判断其贡献 | 任意参数调试 |
| Task Success | 任务是否达到预定义终态 | 请求返回成功 |
| Progress Rate | 在未完全成功时衡量已完成里程碑 | 成功率 |
| `pass^k` | 重复运行中全部/多次通过的可靠性度量，定义须随论文明确 | 单次 pass@k |
| MRR | 正确候选排名倒数的平均值 | Top-k 准确率 |
| Macro F1 | 先按类算 F1 再平均，重视少数类 | Micro F1 |
| SLO | 可量化的服务级目标 | SLA、单次性能数字 |
| Goodput | 满足质量/SLO 的有效吞吐 | 总吞吐量 |
| Instrumentation overhead | 开启采集后额外时间、资源、存储等成本 | 模型调用成本 |
