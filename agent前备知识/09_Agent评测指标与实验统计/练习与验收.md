# 第 9 章练习与验收

## 练习

1. 为同一组结果计算 Top-1、Top-3、MRR、宏 F1，并解释差异。
2. 构造 10 次重复运行，报告均值、中位数、标准差和 95% 区间。
3. 设计四档证据消融：最终输出、消息日志、完整轨迹、完整轨迹+反事实。
4. 写出可能的数据泄漏、judge 偏差和选择性报告风险。

## 验收问题

- 成功率和 `pass^k` 回答的问题有什么不同？
- 宏平均与微平均何时给出相反印象？
- p 值为什么不能代替效应量与置信区间？
- 观测信号更多导致准确率更高，如何排除答案泄漏？

产物：预注册式实验协议 + 空结果表 + 统计分析计划。
