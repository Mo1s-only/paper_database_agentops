# 练习与验收答案：Agent 评测指标与实验统计

## 一、指标计算示例

### 1. Top-k 与 MRR

有 3 个任务，首个正确根因的排名分别为 2、1、无正确项：

- Top-1 = `1/3 = 0.333`；
- Top-3 = `2/3 = 0.667`；
- MRR = `(1/2 + 1/1 + 0)/3 = 0.500`。

必须预先定义“无正确项”的处理、并列名次和候选集是否含真值。若系统不允许输出 `unknown`，Top-k 可能被迫猜测而虚高。

### 2. Macro F1

教学混淆矩阵：

| truth\pred | A | B | C |
|---|---:|---:|---:|
| A | 3 | 1 | 0 |
| B | 1 | 2 | 0 |
| C | 0 | 1 | 2 |

- A：P=3/4，R=3/4，F1=0.750；
- B：P=2/4，R=2/3，F1=0.571；
- C：P=2/2，R=2/3，F1=0.800；
- Macro F1 = `(0.750+0.571+0.800)/3 = 0.707`；
- 单标签多分类 Micro F1 = accuracy = `7/10 = 0.700`。

Macro 让少数类与多数类等权，Micro 按样本量加权；类别不均衡时二者会显著分离。

## 二、十次重复运行统计

教学分数：`70,72,68,75,74,71,73,69,76,72`。

- 均值 = 72.0；中位数 = 72；样本标准差 `s = sqrt(60/9) = 2.582`。
- 若近似独立同分布且均值的 t 区间适用，95% CI：`72 ± t(0.975,9)×2.582/sqrt(10)` = `72 ± 1.847`，即 `[70.153, 73.847]`。

这不是“95% 概率真均值在本次区间内”的贝叶斯陈述；频率学解释是重复采样构造的此类区间有约 95% 覆盖率。对有界、偏斜或强相关的 Agent 指标，应考虑按任务分层 bootstrap；同一任务多次运行不能冒充更多独立任务。

## 三、四项消融设计

完整系统含应用日志 A、trace T、系统事件 S、错误传播图 G。预注册：

| 组 | A | T | S | G | 目的 |
|---|---:|---:|---:|---:|---|
| Full | ✓ | ✓ | ✓ | ✓ | 上界 |
| -System | ✓ | ✓ | ✗ | ✓ | 系统证据增益 |
| -Trace | ✓ | ✗ | ✓ | ✓ | trace 结构增益 |
| -Graph | ✓ | ✓ | ✓ | ✗ | 显式传播建模增益 |
| App-only | ✓ | ✗ | ✗ | ✗ | 最小基线 |

相同任务、失败注入、候选集合、模型和预算；随机化样本顺序；对同一样本用配对比较。主指标可为 root-cause Top-1，次指标为 MRR、未知率、诊断时延和 token。不要只保留效果最大的消融。

## 四、泄漏、judge 与选择性报告

- **泄漏**：诊断输入含金标签、文件名直接写故障类型、修复后日志只出现在正例、同一任务模板跨训练测试。
- **judge 偏差**：评审模型看到方法名、答案长度、参考解释措辞；应盲化、随机顺序，并以人工金标准子集校准。
- **选择性报告**：多次实验后只报最优 seed/指标；应预注册主指标、排除规则、样本量和分析计划，报告全部运行与失败。

## 五、简版预注册方案

```yaml
hypothesis: Full 相比 App-only 提高 root-cause Top-1
primary_metric: Top-1 accuracy
secondary: [MRR, unknown_rate, latency_s, tokens]
unit: 独立任务-故障实例
sample_size: 由预期效应与功效分析确定，当前 AUTHOR_INPUT_NEEDED
randomization: 条件顺序和样本顺序随机
exclusion: 仅排除基础设施完全无输出，规则事先固定
analysis: 配对效应差 + 95% CI；多重次要检验校正
reporting: 所有条件、seed、失败和原始聚合脚本
```

空结果表应在实验前建好，列出 `condition, n, Top1, 95%CI, MRR, latency, tokens, unknown_rate`，避免看到结果后换指标。

## 六、验收问题参考答案

1. **success 与 pass@k？** 单次 success 是一次试验是否成功；pass@k 是允许 k 个候选/独立尝试时至少一次成功的概率估计。k 增大通常提高成功率，但也增加成本，不能与单次成功率直接横比。
2. **Macro/Micro 何时分离？** 类别不均衡且少数类表现与多数类差异大时。Macro 更暴露小类失败，Micro 更代表总体样本正确量。
3. **p 值、效应量、CI？** p 值衡量数据与指定模型的不相容程度，不是原假设为真的概率，也不表示效应大小。应同时报告效应差、区间和实际意义。
4. **更多信号为何会泄漏？** 新信号可能直接编码标签或仅在注入脚本中出现，使模型识别实验机制而非真实根因。需做字段审计、反事实打乱和跨环境验证。

## 七、评分标准（100 分）

手算指标 25；重复统计与假设 20；消融 20；偏差控制 20；预注册 15。仅给均值、不报告变异与样本单位，统计部分最高一半分。
