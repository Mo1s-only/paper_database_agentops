# 第 9 章：Agent 评测指标与实验统计

本章正文：[详细教程](详细教程.md)；学习后完成：[练习与验收](练习与验收.md)；最后对照：[练习与验收答案](练习与验收答案.md)。

## 本章定位

Agent 系统具有非确定性、长链路和多目标特征。只报告一次成功率或平均延迟，会掩盖稳定性、尾部风险、过程进展和归因粒度。

## 学习目标

- 掌握任务结果、过程、稳定性、归因、系统和成本六类指标。
- 理解分母、聚合粒度、宏/微平均、Top-k、MRR、F1 和校准。
- 理解重复运行、`pass^k`、置信区间、效应量和显著性检验。
- 理解基线、强基线、消融、对照变量和威胁有效性。
- 理解标注一致性、judge 校准和数据泄漏。

## 指标分层

| 层 | 核心指标示例 |
|---|---|
| 结果 | Task Success、Task Quality、Constraint Satisfaction |
| 过程 | Progress Rate、Milestone KPI、步骤完成率 |
| 稳定性 | `pass^k`、重复运行方差、失败率、恢复率 |
| 归因 | Agent/Step/Edge Top-1、Top-k、MRR、宏 F1 |
| 系统 | 端到端延迟、TTFT、TPOT、尾延迟、资源、goodput |
| 成本 | Token、模型调用、日志字节、观测开销、单成功任务成本 |

## 实验设计底线

1. 先固定主指标、分母、排除规则和停止条件。
2. 区分自然失败与注入失败，并验证故障确实触发。
3. 包含无方法基线、强基线和关键消融。
4. 对非确定任务重复运行并报告区间，而非只报最好一次。
5. LLM judge 不能作为唯一真值。
6. 同时报告效果增益与观测/计算/人工成本。
