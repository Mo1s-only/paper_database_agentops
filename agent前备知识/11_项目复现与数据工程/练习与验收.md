# 第 11 章练习与验收

## 练习

1. 对一个历史实验目录做文件完整性和哈希清单。
2. 用 SQL 重建 `process → tool → file/network → llm → token` 时间线。
3. 找出 `orphan_response`、空 request、重复调用和缺失关联。
4. 把原始表映射到第 7 章统一 schema，并标注映射置信度。
5. 生成一页“能证明/不能证明”报告。

## 验收问题

- `13/13` 通过支持什么结论？
- 为什么摘要报告数字可能互不一致？
- 原始数据、派生数据和人工标签如何保持血缘？
- 配对 Precision 0.95 的分母与真值怎样得到？

产物：SQL/脚本、数据字典、配对审计表和一页报告。不要把密钥或未脱敏 Prompt 提交到仓库。
