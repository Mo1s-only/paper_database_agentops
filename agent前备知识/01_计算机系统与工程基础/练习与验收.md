# 第 1 章练习与验收

## 练习

1. 画一张 `用户任务 → Agent 进程 → 子进程/工具 → 文件或网络副作用 → 数据库落盘` 图。
2. 写出并运行 5 条 SQLite 查询：表行数、时间范围、进程树、失败工具调用、模型调用与 Token 关联。
3. 解释 `session.db`、`session.db-wal`、`session.db-shm` 的区别。
4. 构造两个并发请求，说明仅按时间最近配对为什么会错。

## 验收问题

- PPID 能证明什么，不能证明什么？
- 为什么单调时钟、墙上时钟和跨机器时间同步会影响 trace？
- 重试为什么会产生重复副作用？如何用幂等键降低风险？
- WSL2 中 eBPF 探针静默失败时应检查哪些条件？
