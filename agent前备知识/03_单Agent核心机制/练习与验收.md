# 第 3 章练习与验收

## 练习

1. 把一个“搜索资料并写摘要”的 Agent 分解为 run、step、model_call、tool_call、observation、outcome。
2. 分别用顺序工作流、ReAct 循环和 planner–executor 画三张状态图。
3. 为每张图标出最大步数、Token 预算、超时、重试和人工介入点。
4. 标出“模型声称完成”和“环境证明确实完成”各需要什么证据。

## 验收问题

- 何时一个程序只是 LLM workflow，而不是自治 Agent？
- step 的边界如何定义，才能用于跨框架比较？
- 为什么 operation tree 比聊天记录更适合故障分析？
- 反思、重试、回滚和重规划的差别是什么？

产物：状态机 + 事件表 + 不可观察变量清单。
