# 双来源真实 API 小样本计划｜2026-10-19

## 目标与证据边界

用户要求真实运行一次 `error-propagation-v1`，并对 AgentRx 的部分真实轨迹进行付费模型调用；两项合计控制在 2 CNY 以内。两个结果须分开报告：前者检验 Claude Code 原生事件与 AgentSight 系统观测的真实跨层数据链；后者只检验公开失败轨迹上的语义诊断输入与输出。AgentRx 的历史轨迹没有本地成对的 AgentSight 原始系统事件，不能算作跨层采集样本。

- 输入：`trajectories/tau-retail/instruction_adherence_failure.json` 的 `traj` 字段，`task_id=12`，26 个步骤。原文件 SHA-256：`8c6579ed82d379012118d2aa8b9fc82a95b004d89ecd76a9890081721acf1137`。
- 独立真值：`data/ground_truth/tau_retail.json` 中 `trajectory_id=12`，根因 `failure_id=6`、`step_number=19`、`failed_agent=Assistant`、类别 `Instruction Adherence Failure`。真值文件 SHA-256：`a0e6fa3b7a8889f6728562c38ca6f708ecf6300806ccebd86639ad901c1f61e9`。模型输入只含 `traj`，不含 `info.task.actions`、`reward_info` 或真值文件。
- 任务：模型读完整轨迹后输出责任步骤、Agent、失败类别和证据；先持久化预测及 CLI 成本，再读取真值评分。该实验是轨迹诊断调用，不会重新执行 Tau Retail 购物环境。

## 合计费用闸门

预算机读文件为 `real-api-error-agentrx-20261019.json`。采用内部规划系数 `10 CNY/USD`，它不是实时汇率。

| 调用 | 上界 USD | 规划 CNY |
|---|---:|---:|
| `error-propagation-v1`：Agent A、B 各一次，每会话最多 0.05 USD | 0.10 | 1.00 |
| AgentRx：仅 `task_id=12` 一次诊断会话 | 0.08 | 0.80 |
| 合计 | 0.18 | 1.80 |

预留 0.20 CNY 的规划余量；不自动重试。每个后续调用必须先读取已发生的 CLI 报告成本并验证剩余额度。供应商最终账单和实际汇率需事后核对，CLI 报告上限不能被表述为最终账单保证。

既有累计账本为 2.183708 USD，超过旧的 2.00 USD 硬停止线。本次用户新的明确授权覆盖本批次不超过 2 CNY 的增量，机读 manifest 将累计硬停线设为 2.363708 USD（旧账本加本批次 0.18 USD 规划上限）。执行前必须刷新并核对累计账本；若出现未入账运行，停止执行并重新计算，不能直接沿用旧总额。

## 执行状态与条件

当前 Windows 环境没有 `claude`、`agentsight` 命令或可用 API 凭据；本机 WSL 尚未启用。用户答复会稍后启用 WSL。当前新 API 调用数为 **0**，新增报告费用为 **0**。

WSL 可用后，先检查 CLI、AgentSight、eBPF 权限、现有凭据和新的累计账本，然后运行 `error-propagation-v1`。只有其两会话都成功且费用记录完整时，才运行 AgentRx 单条轨迹诊断。原生事件、系统 SQLite、任务工件、模型预测、真值评分和两项费用须分目录保存；AgentRx 标签在预测写盘前不得进入模型输入。

在仓库根目录、已配置好的 Linux WSL 中，先运行不调用 API 的样本检查：

```bash
python3 my_paper_coding/experiment_control/run_agentrx_small_probe.py
```

确认累计账本覆盖所有已发生调用后，实际调用顺序如下；两个输出目录必须尚不存在，路径中的 `RUN_ID` 应替换为本次唯一标识：

```bash
python3 my_paper_coding/trace_adapter/capture_real_scenarios.py \
  --scenario error-propagation-v1 \
  --output lab/experiment/experiment_20261019_18/results/error-propagation-RUN_ID \
  --per-session-budget 0.05 \
  --experiment-cost-cap-cny 1.0 \
  --planning-usd-cny-rate 10 \
  --cumulative-manifest my_paper_coding/experiment_control/real-api-error-agentrx-20261019.json \
  --cumulative-ledger my_paper_coding/experiment_control/cost-ledger-20261012-sse-clock.json

python3 my_paper_coding/experiment_control/run_agentrx_small_probe.py \
  --execute \
  --error-run lab/experiment/experiment_20261019_18/results/error-propagation-RUN_ID \
  --output lab/experiment/experiment_20261019_18/results/agentrx-tau12-RUN_ID
```

这些命令只作可复核的执行方案记录，当前没有在本机运行付费模式。若刷新后的账本不同于冻结基线，须先更新本批次 manifest 的基线和硬停线；脚本会拒绝使用不一致账本。第二条命令读取第一条命令的真实费用，超出合计预算时会在调用前退出。
