# Repository Instructions

This folder is the main workspace for the user's graduation thesis on AgentOps, multi-agent system monitoring, tracing, and failure attribution.

For research-related requests in this repository, first consult `research_skills/agentops-thesis-research/SKILL.md` and route the task through the relevant reference workflow. Treat `git_skills.md` as the standing Git procedure.

Default research behavior:

- Work from evidence in this folder first: PDFs, extracted text, paper notes, source code snapshots, weekly reports, topic plans, and existing research notes.
- Keep claims traceable. Separate `VERIFIED`, `INFERRED`, `UNVERIFIED`, and `AUTHOR_INPUT_NEEDED`.
- Never invent papers, citations, DOI values, experimental results, metrics, advisor requirements, or thesis progress.
- For literature tasks, maintain a claim-evidence view rather than only summarizing papers one by one.
- For thesis writing, preserve the user's intended research direction and academic voice; improve structure only after understanding the argument.
- For drafting and revision, prefer the local adaptation of Research Paper Writing Skills first; use Humanizer only as the final prose-polish pass after claims, evidence, citations, and terminology are stable.
- When the user wants to think through a thesis decision, experiment plan, contribution, or defense answer, use the local grill-me style: ask one question at a time, give a recommended answer for confirmation, and save durable notes when the session is substantive.
- For code or experiments, do not overwrite existing work. Inspect status, run focused checks, and document assumptions.
- Before any commit or push, follow `git_skills.md`.

When an answer affects thesis direction, include the next useful research gate: what evidence is missing, what decision can now be made, or what should be validated next.
